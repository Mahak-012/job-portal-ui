# 💼 Job Portal UI

A modern and responsive Job Portal web application built with React and Tailwind CSS. It allows users to browse job listings, view detailed job descriptions, explore company profiles, and navigate through a user dashboard interface.

## 🚀 Live Demo
[Check Live Demo](https://job-portal-ui-six.vercel.app/)

## 🛠️ Tech Stack
- **Frontend:** React.js, React Router
- **Styling:** Tailwind CSS
- **Icons & UI:** Modern responsive components with custom animations

## ✨ Features
- **Job Listings:** Browse through various available job roles.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens.
- **Detailed Views:** Check comprehensive job requirements, responsibilities, and company information.
- **Modern UI/UX:** Built with a sleek, professional dark theme and emerald accents using Tailwind CSS.
